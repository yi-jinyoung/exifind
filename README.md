# Exifind

A lightweight Windows metadata inspector for photos and videos.

## Camera style metadata

- **Panasonic LUMIX:** Photo Style and REAL TIME LUT metadata
- **Fujifilm:** Film Simulation (Film Mode) and related recipe metadata
- **RICOH / PENTAX:** Image Control / ImageTone metadata

Exifind displays these values when the corresponding metadata remains in the original file. It is a read-only inspector and does not modify your media.
